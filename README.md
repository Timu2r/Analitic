# NichaRadar

Аналитика товаров маркетплейсов для селлеров + ИИ-ассистент и генерация карточек.
Фокус — Uzum (Узбекистан/ЦА), плюс Wildberries и Яндекс Маркет.

## Что умеет

- **Поиск ниши / Аналитика** — таблица товаров с баллом привлекательности, ходовостью, спросом, конкуренцией, маржой; фильтры, периоды, сравнение, сезонность.
- **Аналитика категорий** — drill-down: ниши → товары → карточка товара.
- **ИИ-аналитик (чат)** — разбор вопросов на естественном языке («лучший товар в бытовой технике», «что продавать к 1 сентября»); keyword-движок + Google Gemini для сложных вопросов.
- **Генерация карточки** — по фото + названию: SEO-название, описание, буллеты, ключи, промпты для фото (по стилям).
- **Калькулятор маржи** — комиссия по категории, логистика, налог, ROI; валюта по маркетплейсу (сум / ₽).
- Тёмная/светлая тема, история чатов, профиль.

## Честность данных

Точно с витрины: цена, рейтинг, отзывы, число заказов, размер ниши.
Оценка (по снимку, нет истории по дням): продажи/мес, выручка, спрос, маржа.
Реальный тренд «растёт/падает» требует сбора истории по дням (дельта-метод) — roadmap.

## Стек

Vite + React + TypeScript + Tailwind + shadcn-style UI. Данные — реальный снимок Uzum API + демо-данные WB/Яндекс. ИИ — Google Gemini через serverless-прокси (`/api`).

## Запуск

```bash
pnpm install
cp .env.example .env.local   # вставьте свой ключ Google Gemini (без него ИИ работает на fallback)
pnpm dev                     # http://localhost:5173
pnpm build                   # сборка
```

Ключ Gemini: https://aistudio.google.com/apikey
